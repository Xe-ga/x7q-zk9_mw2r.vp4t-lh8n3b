# РУСПАТЧ — архив русских переводов ретро-игр

Статический сайт на [Astro](https://astro.build) с админкой [Sveltia CMS](https://github.com/sveltia/sveltia-cms).
Хостинг — GitHub Pages (бесплатно). Оценки и комментарии — Supabase (бесплатный тариф).

## Как это работает

```
Друг пишет пост в /admin  →  пост сохраняется в GitHub  →  GitHub Actions собирает сайт  →  через 1–2 минуты он на сайте
```

## Что где лежит

| Что | Где |
|---|---|
| Игры (одна папка = одна игра, обложка рядом) | `src/content/games/<slug>/index.md` |
| Записи блога | `src/content/blog/<slug>/index.md` |
| Переводчики, издатели, модераторы | `src/content/translators/`, `src/content/publishers/`, `src/content/moderators/` |
| Список платформ | `src/data/platforms.ts` + `public/admin/config.yml` |
| Типы перевода, жанры | `src/data/taxonomy.ts` + `public/admin/config.yml` |
| Название сайта, Telegram, ключи Supabase | `src/config.ts` |
| Цвета, шрифты, обводки | `src/styles/global.css` (переменные в начале файла) |
| Настройки админки | `public/admin/config.yml` |
| База оценок и комментариев | `supabase/schema.sql` |

> Все игры и записи блога сейчас — **примеры**. Перед запуском удалите их (через админку или просто папки).

## Первый запуск (один раз)

### 1. GitHub
1. Заведите репозиторий, например `ruspatch`, и загрузите туда эту папку (без `node_modules` и `dist`).
2. **Settings → Pages → Source: GitHub Actions.**
3. В `public/admin/config.yml` замените `ВЛАДЕЛЕЦ/ruspatch` на свой `логин/репозиторий`.
4. Сайт появится по адресу `https://логин.github.io/ruspatch/` (если репозиторий назвать `логин.github.io` — то прямо на `https://логин.github.io/`).

### 2. Редактор на сайте
В `src/config.ts` впишите `REPO.name` (`логин/репозиторий`). Тогда редактор карточек `/editor/`
сможет сохранять прямо в GitHub по личному токену модератора.

### 2а. Доступ к админке для друга
1. Добавьте друга в репозиторий: **Settings → Collaborators**.
2. Друг создаёт токен: GitHub → Settings → Developer settings → **Fine-grained tokens** → доступ только к этому репозиторию, право **Contents: Read and write**.
3. Друг открывает `https://…/admin/`, жмёт «Войти с помощью токена доступа» и вставляет токен. Браузер запомнит вход.

### 3. Оценки и комментарии (Supabase)
1. Зарегистрируйтесь на supabase.com, создайте проект (регион — Европа, например Frankfurt).
2. **SQL Editor** → вставьте весь `supabase/schema.sql` → **Run**.
3. Там же выполните строки из конца файла: «соль» (один раз) и по строке на каждого модератора —
   у каждого своё имя и свой личный ключ.
4. **Project Settings → API**: скопируйте *Project URL* и *anon public key* в `src/config.ts`.
5. Пока ключи не вписаны, сайт работает в демо-режиме: голоса и комментарии видит только тот, кто их оставил.

Прежде чем всё строить, проверьте, что у друга (в России, без VPN) открываются
`https://<проект>.supabase.co` и `https://<логин>.github.io`.

### 4. Модерация
Модераторов может быть сколько угодно, у каждого свой ключ.
- Добавить: строка `insert into public.moderators …` из конца `supabase/schema.sql`.
- Войти: страница `/moderator/` → свой ключ. После этого у комментариев появится кнопка «Удалить»,
  а комментарии модератора будут подписаны его именем с пометкой «модератор».
- Кто что удалял: `select * from public.mod_log order by created_at desc;`
- Имена для подписи «Комментарий модератора» на странице игры — раздел «Модераторы» в админке.

## Несколько переводов одной игры
У игры есть список «Переводы». У каждого перевода свои тип, **рекомендация**, переводчики, ссылки,
комментарии и **своя оценка** игроков. На сайте переводы сортируются от лучшей рекомендации к худшей,
а в каталоге показывается лучший.

Метки у перевода:
- **Тип** — как сделан: Ручной / Нейросеть + правки / Нейросетевой / Потрачено.
- **Рекомендация** — насколько советуем: Отлично / Хорошо / Играбельно / Терпимо / Не проверено.
  Ставит модератор, его имя видно при наведении.
- **Состояние** — Полный / Частичный / В процессе, плюс отметки «что не переведено» и сноска.
- **Порт** — перенос готового перевода: отдельно авторы оригинала, портировщики и ссылка на оригинал.

У каждого переводчика есть своя страница (`/translators/<id>/`): все его переводы, статистика
и отзывы игроков.

Оценки игроков привязаны к составу переводчиков: если его поменять у опубликованного перевода,
оценки начнутся с нуля.

## Работа на своём компьютере

```powershell
npm install
npm run dev
```

Сайт откроется на http://localhost:4321. Админка локально — http://localhost:4321/admin/index.html
(кнопка «Работать с локальным репозиторием», нужен Chrome или Edge).

## Поиск

Свой, без сервера: при сборке создаётся `search-index.json`, браузер ищет по нему сам.
- нечёткий поиск по триграммам — прощает опечатки (`harvst moon`);
- неправильная раскладка (`рфкмуые` → harvest);
- кириллицей по латинским названиям (`снатчер` → Snatcher);
- аббревиатуры (`bof` → Breath of Fire);
- ищет по названию, другим названиям, переводчику, издателю, разработчику;
- фильтры по типу перевода, платформе, жанру, переводчику, издателю — со счётчиками;
- состояние сохраняется в адресе — подборкой можно поделиться ссылкой.
