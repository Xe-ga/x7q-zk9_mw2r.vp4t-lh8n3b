Визуальная новелла по аниме Code Geass. Новый герой с потерянной памятью оказывается в центре событий первого сезона и может встать на сторону Лелуша, Британии или кого-то ещё.

Множество веток и концовок, переплетённых с сюжетом сериала.

## Как запустить

Для эмулятора есть HD-шрифт и текстуры: распакуйте их в папку `PSP/TEXTURES` эмулятора и включите замену текстур (replace textures).
